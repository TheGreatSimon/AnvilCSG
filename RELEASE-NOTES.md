# Anvil CSG Beta 2: free legacy preview

Here's Beta 2 for anyone who wants to try building a map with Anvil before the newer paid release arrives.

Download **AnvilCSG-Beta2-Preview.zip** below. Extract it, read the included licence, and import **AnvilBeta2.unitypackage** into a separate Unity project. Open **Tools > Anvil > Workspace** to get started.

This is the original Beta 2 package, unchanged. It is an older, unsupported build with known bugs, not the latest beta. Back up your work and don't import it over another Anvil installation. The bundled native xatlas UV plugin is Windows x64 Editor-only. Newer tutorials and docs may show features this version doesn't have.

You can use the preview in games, including commercial games, with a **Made with AnvilCSG** credit. Anvil's code cannot be modified or redistributed as a tool. Third-party components keep their original licences. Read **LICENSE.md** in the ZIP for the full terms.
